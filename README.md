The winning fail: **"I told my boss I'd be late because my car wouldn't start, but autocorrect changed it to 'my cat wouldn't fart' and now HR wants a meeting about my cat's diet."** — a single letter turns a broken car into a flatulent cat, and the joke keeps escalating from a late excuse to an HR meeting about the cat's diet, so the slip is clear, the wrong word is a surprise, and the punchline lands on the last word. The program scores a small table of candidate one-line autocorrect fails on clarity of the slip, surprise of the wrong word and first-read landing, picks the best one, checks it against the competition's gate, and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
